Title: Feature Request - Coin: Flexible SIP Execution & Skip Option (+ Bulk Actions)

> Feature Request - Coin: Flexible SIP Execution & Skip Option (+ Bulk Actions)
>
> Hello Team,
>
> I’d like to suggest an enhancement to the SIP functionality that would give investors more flexibility and ease of use.
>
> Use Case:
>
> SIPs are executed automatically on their scheduled date, as they should (e.g., the 28th of each month). However, there are scenarios where I may see a market opportunity and prefer to execute my SIP earlier; for example, on August 14th instead of waiting until the 28th.
>
> Proposed Feature:
>
> Add an “Execute Now” option for the SIP.
>
> While executing early, provide a checkbox/option to skip the upcoming scheduled execution (to avoid double execution for the same month).
>
> Extended Request (Bulk Actions):
>
> A bulk option to apply “Execute Now” or “Skip This Month” across multiple SIPs at once.
>
> Similarly, a bulk reschedule option to adjust SIP dates, rather than editing them one by one.
>
> Current Workaround:
>
> Right now, the only way to handle this is by editing each SIP and backdating it so it won’t trigger again this month, then placing my order manually, which is quite time-consuming.
>
> This feature would make SIP investing more convenient, especially for investors managing multiple SIPs.
>
> Thanks for considering this!
